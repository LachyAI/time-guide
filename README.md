# Lachy OS — Voice Agent Suite

8 custom AI voice agents for personal development, productivity, and coaching. Real conversations, not chatbot scripts.

**[Live →](https://time-guide-iota.vercel.app)**

## Agents

| Agent | Purpose |
|-------|---------|
| **Time Guide** | Daily scheduling and time management |
| **Future Self** | Long-term vision and goal alignment |
| **Stoic Advisor** | Stoic philosophy applied to real decisions |
| **Content Sparring** | Brainstorm and pressure-test content ideas |
| **Sales Coach** | Practice objection handling and pitch delivery |
| **Weekly Review** | Guided end-of-week reflection |
| **Morning Brief** | Start-of-day priorities and intention setting |
| **Evening Wind-Down** | End-of-day reflection and gratitude |

## Stack

- Next.js (App Router)
- ElevenLabs Conversational AI
- Claude (Sonnet) for agent intelligence
- Tailwind CSS
- Deployed on Vercel

## Run Locally

```bash
npm install
npm run dev
```

Requires `.env.local` with ElevenLabs API credentials.
